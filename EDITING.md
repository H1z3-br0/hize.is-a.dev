# Как править сайт руками

Всё содержимое — в одном файле: **`src/config/site.ts`**. Разметку трогать не нужно
почти никогда. Ниже рецепты под конкретные задачи.

## Правила, которые ломать нельзя

1. **Каждый текст задаётся сразу на двух языках** — `{ ru: '…', en: '…' }`.
   Забудете `en` — сборка упадёт с понятной ошибкой, а не молча.
2. **Кавычки внутри текста экранировать не нужно**, если строка в одинарных
   кавычках, а внутри — «ёлочки» или `“…”`. Если нужен апостроф — возьмите
   строку в обратные кавычки: `` `it's` ``.
3. **HTML разрешён ровно в одном поле** — `notation` у проекта. Во всех
   остальных полях теги выведутся текстом, как есть.
4. **Спецсимволы** — см. «Грабли» в `README.md`. Коротко: не набирайте `ₙ`,
   `ᵀ` и прочие надстрочные знаки напрямую, их нет в шрифте.

После любой правки:

```bash
npm run check     # ловит опечатки и забытый перевод
npm run build
npm run preview   # http://localhost:4321
```

## Поменять имя, позиционирование, «сейчас»

```ts
export const name: L = {
  ru: 'Имам Чобанов',
  en: 'Imam Chobanov',
};

export const lead: L = {          // крупная строка под именем
  ru: 'Криптография решёток. Ученик СУНЦ МГУ.',
  en: 'Lattice cryptography. Student at AESC, Moscow State University.',
};

export const subLead: L = {       // строка помельче, серым
  ru: 'CTF в команде 4x10m, поиск уязвимостей в багбаунти.',
  en: 'CTF with 4x10m, vulnerability hunting in bug bounty.',
};

export const now: L<string[]> = { // каждый элемент массива — отдельный абзац
  ru: ['первый абзац', 'второй абзац'],
  en: ['first paragraph', 'second paragraph'],
};
```

**Если поменяли `name`, `lead` или `subLead`** — перерисуйте картинку превью:

```bash
node --experimental-strip-types tools/make-og.mjs
```

## Проекты

Массив `projects`. Порядок в массиве = порядок на странице, номера
проставляются сами.

```ts
{
  id: 'lambda',                                   // латиницей, для себя
  tools: ['Rust'],                                // строка под названием
  repo: 'https://github.com/H1z3-br0/Lambda',     // null — ссылки «код» не будет
  notation: 'Λ₁ ≅ Λ₂',                            // необязательно, одна строка
  text: {
    ru: {
      title: 'Lambda',
      summary: 'Одно предложение сути. Видно в свёрнутом виде.',
      task: 'Что за задача.',        // дальше — три абзаца,
      approach: 'Как решается.',     // они раскрываются
      done: 'Что уже сделано.',      // по «подробнее»
    },
    en: { title: '…', summary: '…', task: '…', approach: '…', done: '…' },
  },
}
```

**Убрать проект** — удалите объект целиком. **Добавить** — скопируйте соседний
и замените поля. **Переставить** — поменяйте местами в массиве.

Поле `notation` — единственное, где работает разметка. Надстрочный и
подстрочный набираются так:

```ts
notation: 'Λ₁ ≅ Λ₂ ⟺ ∃U ∈ GL<sub>n</sub>(ℤ) : U<sup>T</sup>G₁U = G₂',
```

В обычных абзацах пишите `GL(n, ℤ)`, а не `GLₙ(ℤ)`.

## Стек

Массив `stack`. Каждый профиль — отдельный блок.

```ts
{
  id: 'crypto',
  label: { ru: 'криптография', en: 'cryptography' },
  tools: ['SageMath', 'Magma', 'CyberChef'],
  note: { ru: 'необязательная ремарка', en: 'optional note' },
}
```

Название профиля лежит рядом с инструментами — добавить четвёртый профиль
можно одним объектом, больше нигде ничего править не нужно.

## Разборы CTF

```ts
export const writeups: Writeup[] = [
  {
    url: 'https://habr.com/…',
    date: '2026-08-01',              // ГГГГ-ММ-ДД, сортировка сама, новые сверху
    category: 'crypto',
    text: {
      ru: { title: 'Название разбора', event: 'Название соревнования' },
      en: { title: 'Writeup title', event: 'Event name' },
    },
  },
];
```

Пока массив пуст, **раздела нет вообще** — ни заголовка, ни «скоро будет».
Добавите первый элемент — раздел появится сразу на странице, в палитре команд,
в терминале и в обеих текстовых визитках.

## Разделы страницы

```ts
export const sections = [
  { id: 'now', label: { ru: 'сейчас', en: 'now' } },
  …
] as const satisfies readonly { id: string; label: L }[];
```

Здесь задаётся и порядок, и подписи в левом поле. Отсюда же берутся якоря
(`#now`), пункты палитры, команда `open` в терминале и заголовки в `card.txt` —
поэтому переименовать раздел можно в одном месте.

Добавить новый раздел — задача уже не только для конфига: нужен ещё компонент
в `src/components/` и строка в `src/components/Page.astro`. Компонент проще
всего скопировать с `Stack.astro`, он самый короткий.

## Контакты, домен, PGP

```ts
export const identity = {
  domain: null,                    // 'example.com' — и он разойдётся везде
  email: 'pkd12305@gmail.com',
  github: 'H1z3-br0',
  telegram: 'hize_k',
  pgp: null,                       // появится блок отпечатка, см. ниже
  ctftimeTeam: { alias: '4x10m', id: 418607 },
};
```

**Домен.** Пока `null`, везде подставляется `localhost:4321`. Поставите свой —
он сам разойдётся по `canonical`, og, `security.txt`, `robots.txt`, `sitemap.xml`
и подсказке `curl`. Отдельно впишите его же в `deploy/nginx.conf` вместо
`ПОСТАВЬТЕ_ДОМЕН` (там два места).

**PGP.** Пока `null` — блока отпечатка на странице нет. Появится так:

```ts
pgp: {
  fingerprint: 'AAAA BBBB CCCC DDDD EEEE  FFFF 0000 1111 2222 3333',
  keyUrl: 'https://example.com/key.asc',
},
```

Вместе с блоком появится кнопка «скопировать» и строка `Encryption`
в `security.txt`.

## Строки интерфейса

`ui` — подписи кнопок, подсказки, страница 404. `shellText` — палитра команд и
терминал. Оба описаны интерфейсами `UiStrings` и `ShellStrings`: добавите ключ
в `ru` и забудете в `en` — `npm run check` скажет об этом до сборки.

## Флаг и задача

Части флага и подписи задачи — в `src/config/challenge.ts`:

```ts
export const flagPart1 = 'axiom{p4sh4lk0-';   // HTML-комментарий в начале <head>
export const flagPart2 = '1_4m_';             // robots.txt, base64
```

Третья часть лежит только шифротекстом. Поменять её и ответ:

```bash
node tools/make-challenge.mjs '<ответ>' '<третья часть флага>'
```

Ответ никуда не сохраняется. Условие задачи (матрицу и цель) правьте прямо в
`tools/make-challenge.mjs`, тексты вокруг задачи — в `challengeText`
в `src/config/challenge.ts`.

## Внешний вид

Всё в `src/styles/main.css`, в самом начале.

```css
:root {
  --paper:   #e9eef0;   /* фон */
  --sheet:   #f7fafa;   /* панели: рамка канваса, диалоги */
  --rule:    #c4d3d9;   /* линии и сетка */
  --ink:     #16283c;   /* основной текст */
  --ink-2:   #4a5f70;   /* вторичный текст */
  --accent:  #b02334;   /* красная ручка, единственный акцент */

  --fs-body: 1.25rem;   /* кегль основного текста */
  --measure: 35.5rem;   /* ширина колонки — держите около 68 знаков */
  --cell:    38px;      /* шаг фоновой сетки */
}
```

Тёмная тема — те же переменные ниже, в двух местах:
`@media (prefers-color-scheme: dark)` и `:root[data-theme='dark']`.
**Правьте оба, значения должны совпадать.**

Русская версия набрана на 4% крупнее — в кириллице почти нет выносных
элементов, и при равном кегле она читается мельче:

```css
html[lang='ru'] {
  font-size: 104%;
  --measure: 40rem;
}
```

Если меняете `--measure`, держите строку в пределах 70 знаков: кириллица в этом
шрифте на 11% шире латиницы, поэтому меры и разные.

## Если сломалось

| Симптом | Причина |
|---|---|
| `npm run check` ругается на отсутствующее свойство | добавили ключ в `ru`, забыли в `en` |
| На странице видно `<sub>` или `<b>` текстом | HTML работает только в `notation` |
| Вместо символа квадрат | этого знака нет в шрифте, см. «Грабли» в README |
| Раздел не появился | у `writeups` пустой массив — так и задумано |
| Сборка падает на `npm run data` | не должна: при недоступной сети берётся кэш |

Откатить всё к последнему рабочему состоянию: `git checkout src/config/site.ts`.
